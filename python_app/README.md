# 🎯 12가지 프롬프트 기법 셀렉터 (Python CLI)

AI 프롬프트 엔지니어링의 12가지 핵심 기법을 CLI로 쉽게 활용할 수 있는 Python 애플리케이션입니다.

## 📚 지원하는 12가지 기법

### 🟢 쉬운 난이도
1. **역할 지정 기법** - 전문가 역할 부여
2. **마크다운 활용 기법** - 구조화된 문서 작성
3. **형식 지정 기법** - JSON/CSV 등 형식 고정
4. **이어쓰기 기법** - 자연스러운 문장 완성

### 🟡 보통 난이도
5. **Few-Shot 기법** - 소수의 예시로 패턴 학습
6. **후카츠 프롬프트 기법** - 4단계 구조화
7. **Q&A 기법** - 질문-답변 패턴 학습
8. **할루시네이션 방지 기법** - 사실 기반 답변

### 🔴 어려운 난이도
9. **슌스케 템플릿 기법** - 프로그래밍적 설계
10. **Chain of Thought 기법** - 단계별 추론
11. **멀티 페르소나 기법** - 다각적 분석
12. **ReAct 기법** - 추론과 행동 반복

## 🤖 지원 AI 모델

- **ChatGPT** (OpenAI GPT-4o)
- **Claude** (Anthropic Claude 3.5 Sonnet)
- **Gemini** (Google Gemini 2.0 Flash)

## 🚀 설치 및 실행

### 1. 필수 요구사항

- Python 3.7 이상
- pip (Python 패키지 관리자)

### 2. 의존성 설치

```bash
cd python_app
pip install -r requirements.txt
```

### 3. API 키 설정 (선택사항)

API 키를 환경변수로 설정하면 매번 입력하지 않아도 됩니다.

```bash
# .env 파일 생성
cp .env.example .env

# .env 파일 편집하여 API 키 입력
nano .env
```

또는 직접 환경변수 설정:

```bash
export OPENAI_API_KEY="your_api_key_here"
export ANTHROPIC_API_KEY="your_api_key_here"
export GEMINI_API_KEY="your_api_key_here"
```

### 4. 실행

```bash
python main.py
```

또는 실행 권한 부여 후:

```bash
chmod +x main.py
./main.py
```

## 📖 사용 방법

### 기본 흐름

1. **AI 모델 선택**
   - ChatGPT, Claude, Gemini 중 선택
   - 마지막 사용 모델이 표시됩니다

2. **API 키 입력**
   - 저장된 API 키가 있으면 재사용 가능
   - 새 키 입력 시 저장 여부 선택 가능

3. **프롬프트 기법 선택**
   - 난이도별로 그룹화되어 표시
   - 12가지 기법 중 하나 선택

4. **정보 입력**
   - 선택한 기법에 필요한 정보 입력
   - 여러 줄 입력은 빈 줄 입력으로 종료

5. **프롬프트 확인**
   - 생성된 프롬프트 미리보기
   - 전송 전 확인 가능

6. **결과 확인 및 저장**
   - AI 응답 결과 표시
   - 파일로 저장 가능 (results/ 디렉토리)

### 주요 기능

#### 🔐 API 키 관리
- 환경변수 우선 지원 (`.env` 파일)
- 설정 파일에 저장 가능 (`~/.12prompt/config.json`)
- 안전한 저장 (홈 디렉토리 숨김 폴더)

#### 📝 히스토리 관리
- 최근 100개 작업 자동 저장
- 프롬프트와 결과 요약 저장
- 위치: `~/.12prompt/history.json`

#### 💾 결과 저장
- 자동 타임스탬프 파일명
- `results/` 디렉토리에 저장
- 형식: `result_{기법}_{모델}_{시간}.txt`

#### ⌨️ 편리한 입력
- 여러 줄 입력 지원
- 기본값 제공
- Ctrl+C로 안전한 종료

## 🎓 사용 예시

### 예시 1: Few-Shot 감정 분석

```
기법 선택: Few-Shot 기법

예시 1 입력: "이 제품 정말 훌륭해요!"
예시 1 출력: "긍정 (95%)"

예시 2 입력: "배송이 너무 늦어요"
예시 2 출력: "부정 (90%)"

예시 3 입력: "그냥 그래요"
예시 3 출력: "중립 (80%)"

실제 분석: "와 대박! 완전 최고예요!"
```

### 예시 2: 역할 지정 - 세무 상담

```
기법 선택: 역할 지정 기법

역할: 세무사
경력: 15년 경력, 공인회계사
성격: 친절하고 상세한 설명
업무 범위: 세금 신고, 절세 전략
제약사항: 최종 결정은 세무사 상담 권장

질문: 프리랜서 종합소득세 절세 방법은?
```

### 예시 3: Chain of Thought - 수학 문제

```
기법 선택: Chain of Thought 기법

문제: 시속 60km로 달리는 차가 3시간 30분 동안
      얼마나 이동하나요? 단, 중간에 30분 휴식했습니다.

검증: 속도 × 시간 공식 사용, 단위 확인
```

## 🔍 문제 해결

### API 오류

```
❌ OpenAI API 오류: Invalid API key
```

**해결 방법**: API 키 확인 및 재입력

### 네트워크 오류

```
❌ 오류 발생: Connection timeout
```

**해결 방법**: 인터넷 연결 확인, 타임아웃 대기

### 설정 파일 오류

설정 파일 위치: `~/.12prompt/`

강제 초기화:

```bash
rm -rf ~/.12prompt/
```
